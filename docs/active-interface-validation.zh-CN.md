# EOS-1V N3 主动驱动验证

## 最终验证结果

UNO R4 WiFi 已直接完成 EOS-1V 的初始握手、设备信息读取和退出：

```text
FF RX (1/1): F4
F6 RX (17/17): F6 0E 38 FF 1A 17 C1 18 10 1C 00 04 00 00 00 0D 7E
F1 RX (6/6): F1 03 01 00 34 35
FULL HANDSHAKE OK
EXIT RX1 (1/1): F2
```

F6和F1响应与原厂 ES-E1 抓取结果一致。

## DATA-A 电气行为

- 空闲电压约4.7 V。
- 低电平104 us后，仅释放线路可在约16.15 us内恢复HIGH。
- 连续低电平312 us后，相机弱上拉停止维持，单纯开集电极无法恢复HIGH。
- 10 us主动HIGH足以将线路恢复为HIGH，但相机弱上拉不会在后续低位后持续生效。
- 初始FF要求输出在空闲时保持隔离；持续推挽HIGH会导致相机不响应FF。

因此发送器必须使用两条隔离路径：

1. NPN开集电极产生LOW；
2. 二极管隔离的GPIO产生HIGH；
3. 初始FF仍使用开集电极释放HIGH；
4. 首次连续两个以上LOW位后进入主动HIGH模式，之后在整个会话中主动维持HIGH和字节间空闲；
5. 退出或失败后关闭两个驱动。

## 验证电路

```text
D4 --10k-- 2N2222 B
B  --100k-- E
E  -------- EOS COMMON + UNO GND
C  --330R-- EOS FOCUS / DATA-A

D5 --1k-- 1N4007 anode
1N4007 cathode/stripe -- EOS FOCUS / DATA-A

EOS SHUTTER / DATA-B --5.1k-- D0 / Serial1 RX
```

D1和D2在最终通信电路中不连接。

## 退出变体

本次UNO主动会话中，首个F2直接得到F2，属于单阶段退出。原厂软件抓包还观察到两阶段退出：

```text
F2 -> F4
F4 acknowledgement
F2 -> F2
```

实现应同时接受两种退出响应。

## 设置与胶卷数据主动读取

最终固件已在不经过 ES-E1 的情况下完成以下只读流程：

- `E8`：11字节响应；
- `FC`：5字节响应；
- `E1`：5字节响应；
- `D5`、`D7`、`D9`：各13字节响应；
- `D1`：14字节响应；
- `E3 21`：36字节卷头；
- `E4 21`：36字节拍摄记录；
- `E4 01 00 00`：当前卷结束；
- `E3 01 00 00`：全部卷结束。

实机完整下载得到两卷、共50条记录，与此前 ES-E1/Windows 抓包中的两卷25条记录完全对应。完成全部E3/E4读取后，相机接受单阶段 `F2 -> F2` 退出。

删除全部拍摄数据后又验证了空数据路径：`E1 02 00 00 00` 时固件直接返回零卷、零记录，不再发送 E3/E4，并通过单阶段 `F2 -> F2` 正常退出。固件同时在已建立会话后的下载失败路径尝试 F2 清理，避免仅释放线路却把相机留在半开会话。

固件按照 EOS-1V 的参数允许读取最多100卷。100卷是防止异常响应造成无限循环的保护上限；正常下载仍以 `E3 01 00 00` 全部结束标记终止。每卷40条的保护上限覆盖36张胶卷，正常卷尾仍由 `E4 01 00 00` 决定。

相机会异步发送 `F4`，并可能插入任何只读命令的响应位置。可靠实现必须把它作为带内同步事件处理：回送F4并重试原命令，不能只在固定流程位置等待F4。

## 最终 DATA-A 驱动状态机

单纯开集电极和持续推挽均不能覆盖完整协议。最终实现采用两个隔离驱动支路：

```text
LOW： D4 --10k-- 2N2222 B，E接COMMON，C经330R接DATA-A
HIGH：D5 --1k-- 1N4007阳极，二极管阴极/环带端接DATA-A
RX：  DATA-B --5.1k-- D0/Serial1 RX
```

状态规则：

1. 会话开始前，LOW和HIGH支路都关闭；
2. 初始FF使用NPN拉低起始位，HIGH位只释放线路；
3. 首次出现连续两个或更多LOW位后，进入主动HIGH模式；
4. 主动HIGH模式下，逻辑HIGH及字节间空闲由D5经二极管维持；
5. 发送LOW前先关闭D5，再开启NPN；
6. 正常退出或错误停止后关闭两路驱动。

逐位回读已验证：

```text
FF: 0111111111
F4: 0001011111
F6: 0011011111
```
