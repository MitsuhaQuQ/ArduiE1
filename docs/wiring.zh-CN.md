# EOS-1V / ES-E1 到 UNO R4 接线

本文同时记录当前稳定桥使用的主动通信电路，以及早期抓包使用的被动监听
电路。运行 `ra4_camera_bridge` 时必须使用“主动通信接线”，不能把下面的
D2/D3 被动监听接线当成产品桥接电路。

## Canon N3 线路定义

| Canon 线路 | 普通快门功能 | EOS-1V PC 模式功能 |
|---|---|---|
| `COMMON` | 公共端/参考端 | 信号参考和回路返回 |
| `FOCUS` | 半按/合焦触点 | 双向 `DATA-A` |
| `SHUTTER` | 全按/快门触点 | 双向 `DATA-B` |

这些名称表示电气功能，不保证线色或插头编号。插头正反视角可能造成镜像，
接线前必须用万用表从实际插头触点确认三条导线。

## 稳定桥主动通信接线

```text
LOW：D4 --10k-- 2N2222 基极
     2N2222 基极 --100k-- 发射极
     2N2222 发射极 -- COMMON/GND
     2N2222 集电极 --330R-- FOCUS/DATA-A

HIGH：D5 --1k-- 1N4007 阳极
      1N4007 阴极/色环端 -- FOCUS/DATA-A

RX：SHUTTER/DATA-B --5.1k-- D0 / Serial1 RX
COMMON -- UNO GND
```

D1/TX 和 D2 保持断开。D4/D5 在启动时必须处于释放状态。上传或更换固件时
先断开 DATA-A 和 DATA-B；确认固件、阻值、三极管引脚及二极管方向后再连接
相机。UNO 应先上电，相机进入 PC 模式后再由上位机开始 O1 会话。

## 早期被动监听接线（仅用于抓包）

### 引脚分配

| N3 线路 | UNO R4 WiFi | 用途 |
|---|---:|---|
| `FOCUS / DATA-A` | `D2` | 通道 A，只输入 |
| `SHUTTER / DATA-B` | `D3` | 通道 B，只输入 |
| `COMMON` | `GND` | 信号参考地 |

不要把 UNO 的 TX 或任何输出引脚接到 N3。不要在 D2、D3 上启用内部上拉。

### 每路保护电路

两路各自搭建一套相同电路。推荐每路串联两只 5.1kΩ，合计约 10.2kΩ。如果电阻数量不足，每路一只 5.1kΩ也可以用于已经测得为 0–5V 的首次采集。

```text
N3 DATA ── 5.1kΩ ── 5.1kΩ ──●──────── UNO D2 或 D3
                              │
                              ├───|>|─── UNO +5V
                              │   高侧 1N4007
                              │   无环端接●，色环端接+5V
                              │
UNO GND ─────────────────|>|──┘
                         低侧 1N4007
                         无环端接GND，色环端接●
```

其中 `●` 是受保护的输入节点：串联电阻、UNO 输入以及两只二极管在这里相接。

### 二极管色环方向

- 高侧二极管：无色环端（阳极）接输入节点，色环端（阴极）接 UNO `+5V`。
- 低侧二极管：无色环端（阳极）接 UNO `GND`，色环端（阴极）接输入节点。

正常 0–5V 信号下两只二极管均不导通。不要反接高侧二极管，否则 UNO 的 5V 电源会经二极管送入相机信号线。

### 完整连接

```text
EOS/ES-E1 FOCUS/DATA-A
        │
        └── 5.1k ── 5.1k ── A节点 ── UNO D2
                                  ├── 高侧1N4007 ── UNO +5V
                 UNO GND ──低侧1N4007──┘

EOS/ES-E1 SHUTTER/DATA-B
        │
        └── 5.1k ── 5.1k ── B节点 ── UNO D3
                                  ├── 高侧1N4007 ── UNO +5V
                 UNO GND ──低侧1N4007──┘

EOS/ES-E1 COMMON ───────────────────── UNO GND
```

面包板电源轨可能在中间断开。如果使用跨越整块面包板的 `+5V` 或 `GND` 轨，先用万用表导通档确认两段已经连接。

### 断电检查

在相机、ES-E1 和 UNO 均未上电时检查：

1. `COMMON` 到 UNO `GND` 导通。
2. `FOCUS/DATA-A` 到 D2 的电阻约为 10.2kΩ（使用一只时约为 5.1kΩ）。
3. `SHUTTER/DATA-B` 到 D3 的电阻同上。
4. 两条 N3 数据线之间不应短路。
5. 任一数据线均不应直接与 `+5V` 或 `GND` 短路。
6. 再次按色环确认两路共四只二极管的方向。

### 上电与采集顺序

1. 先把固件上传到 UNO，并确认 D2、D3 配置为 `INPUT`。
2. 先给 UNO 上电，使其 `+5V` 钳位电源已经存在。
3. 再连接或开启 ES-E1 与相机。
4. 开始实际通信前确认相机处于 PC 模式。
5. 启动边沿采集，然后在 Remote 中执行一次只读操作。
6. 正常退出 Remote。
7. 停止采集，然后再关闭或断开设备。

被动监听中的 1N4007 适合已完成的低速抓包验证，但不是产品级保护器件。
正式硬件应评估更快的肖特基二极管或高阻缓冲/隔离前端，并重新验证电平、
边沿、过冲和驱动冲突。
